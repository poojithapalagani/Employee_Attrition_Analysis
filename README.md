# Employee_Attrition_Analysis
📊 Employee Attrition Prediction & Workplace Analysis – Project Overview

This project focuses on analyzing employee behavior and predicting employee attrition using Machine Learning techniques. The main objective was to identify employees who are at risk of leaving the organization and uncover the key factors influencing employee turnover.

The dataset consisted of 20,000 employee records with demographic, job-related, behavioral, and satisfaction-based features such as age, department, overtime, training frequency, job satisfaction, work-life balance, and monthly income.

🔹 Key Objectives:
Predict employee attrition using classification models
Identify major factors affecting employee turnover
Analyze employee behavior through Exploratory Data Analysis (EDA)
Segment employees using clustering techniques
Generate actionable HR and business insights
🔹 Technologies & Techniques Used:
Python
Pandas & NumPy
Matplotlib & Seaborn
Scikit-learn
Machine Learning Models:
Logistic Regression
Random Forest
KMeans Clustering
🔹 Data Preprocessing:
Removed irrelevant columns
Encoded categorical variables
Scaled numerical features using StandardScaler
Applied OneHotEncoding for categorical features
Performed train-test split with stratified sampling
🔹 Exploratory Data Analysis (EDA):

The analysis revealed several important business insights:

Employees working overtime had significantly higher attrition rates
Low job satisfaction and poor work-life balance strongly contributed to employee turnover
Marketing and HR departments showed slightly higher attrition levels
🔹 Model Performance:

Different machine learning models were trained to predict employee attrition:

Logistic Regression provided moderate performance
Random Forest initially showed imbalance issues
Threshold tuning improved attrition recall to 93%, making the model more effective in identifying high-risk employees
🔹 Feature Importance:

The most influential factors affecting attrition included:

Monthly Income
Age
Distance from Home
Years at Company
Promotions
Training Frequency
Work Experience History
🔹 Clustering Analysis:

KMeans clustering was applied to identify employee segments, but the results showed that attrition patterns were distributed across multiple employee groups rather than isolated clusters.

🔹 Business Recommendations:
Improve employee work-life balance
Reduce overtime workload
Increase career growth opportunities
Enhance employee engagement programs
Monitor high-risk employees proactively using predictive analytics
🔹 Conclusion:

This project successfully demonstrated a complete end-to-end machine learning workflow for employee attrition prediction and workplace analysis. It highlights how data analytics and predictive modeling can help organizations improve employee retention, reduce turnover costs, and support strategic HR decision-making.
